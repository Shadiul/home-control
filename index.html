    Tuya Cloud

    Needed once to get the LED's local key, and used for control whenever the LAN route is blocked.
    1. Sign up free at iot.tuya.com, then go to Cloud → Development → Create Cloud Project (choose "Smart Home" and your data centre).
    2. In the project, open Devices → Link App Account → Add App Account and scan the QR code with the Smart Life / Tuya Smart app (Me → scan icon).
    3. Copy the Access ID and Access Secret from the project's Overview page into the fields below.
